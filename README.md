# فاليت (Vallet) — MVP

منصة عربية RTL لتنظيم سوق الفاليه في عمّان (وضع تجريبي).

## التشغيل محلياً

```bash
cd /workspace/vallet-mvp
npm install
npm run dev
```

افتح http://localhost:5173

## الأدوار التجريبية

بدّل من الشريط العلوي: **حكومة / مشغّل / موظف / سائق** — بدون مصادقة حقيقية. البيانات في `localStorage`.

- **سائق**: موقع GPS (أو دبوس تجريبي في عمّان) → أقرب مواقف مرخّصة → طلب تسليم سيارة.
- **مشغّل**: صندوق طلبات السائقين → قبول وتعيين موظف → إنشاء زيارة/إيصال.
- **موظف**: دخول/خروج يدوي كما السابق مع إيصال الزيارة.
